## Project Description

A simple interactive polling web application built using HTML, CSS, and JavaScript.

It allows users to vote for their favorite technology (HTML, CSS, JavaScript) and view live results using a dynamic chart.

The application updates results in real time and stores data using Local Storage so votes are not lost after refresh.

---

## Features

- Vote for HTML, CSS, or JavaScript
- Live updating results using Chart.js
- Interactive doughnut/pie chart visualization
- Real-time total vote calculation
- Reset votes functionality
- Data saved using Local Storage (persists after refresh)
- Clean and responsive UI design

---

## Tech Stack

- HTML
- CSS
- JavaScript (Vanilla JS)
- Chart.js

---

## Project Functionality

- Users can click on voting buttons (HTML, CSS, JS)
- Votes update instantly in UI
- Chart updates dynamically based on votes
- Total votes calculated automatically
- Reset button clears all stored votes
- Data persists even after page refresh using Local Storage
